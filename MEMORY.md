# Memória do projeto

Base: PWA Framework 1.1.0-website.4. Interfaces independentes: pwa/ Framework7, admin/ shadcn-vue e website/ Nuxt SSR. Configuração manual somente em .env.foundation; preservar contas, APP_KEY, dados, volumes e estado. Sem loja/editor comercial neste ciclo.

Sprints 1–3 do website validadas pelo responsável no Windows: bootstrap/Nginx, formulários/máscaras, sessão website/PWA nos dois sentidos, recuperação por e-mail e isolamento administrativo. Suíte Laravel/MySQL: 55 testes/446 assertions; Pint, 37 testes PWA e 18 admin/lint/build aprovados. Envio por Vite também confirmado; recuperação respeita intervalo de 60s por conta compartilhado entre interfaces. VPS/HTTPS e HMR Windows não têm aceite específico registrado.

Sprint 4 implementada: exemplo público em website_demo_content (tabela inicialmente vazia), comando website:content para publicar/limpar somente id=1, GET Laravel anônimo com seleção explícita de campos e bridge Nuxt sem cookies/Authorization. SSR entrega conteúdo no HTML; useFetch reaproveita só a hidratação, atualiza em consulta/navegação/foco e oculta dado anterior durante loading/erro/offline. Interpolação escapada e no-store; sem cache privado ou mudanças na autenticação. Bootstrap aplica migration, publica website e confere HTML/buildId e JSON /_content; não exige nova imagem do executor, serviços ou configuração central.

Validação local desta entrega: 43 PHPUnit sem grupo MySQL (325 assertions), Pint, 45 testes bootstrap com Engine/Compose simulados, 37 PWA, 18 admin e 17 website (8 HTTP/SSR/contratos e 9 DOM), além dos builds das três interfaces aprovados. SSR real com backend simulado confirmou alteração do HTML sem rebuild/restart, conteúdo vazio/falha e isolamento de dados privados. A suíte MySQL completa, SMTP real e navegador/Docker Windows não foram executados aqui; evidências anteriores não homologam a nova migration.
